# Decisions from practice

The ADRs in the folder above record decisions made for this lab. The ADRs here record the kind of
decision an architect makes at a regulated organisation, where the forces are different: more teams,
change control, auditors and existing estates.

They contain no employer code or configuration. Some decisions are generalised from experience; none
names an organisation, a system, a person or a number that could identify one.

Each one uses the same template as the lab ADRs (`../0000-template.md`), plus a short section on how
the lab version differs and why.
